## 60-second pitch: "How would you set up Jenkins at a company?"

> Jenkins on Kubernetes via Helm, controller image with pinned plugins, configured 100% by JCasC from Git, jobs generated by Job DSL / org folders. Controller has zero executors; builds run in ephemeral pod agents on an autoscaled spot node pool. SSO with OIDC and role-based access mapped to IdP groups. Secrets in Vault or AWS Secrets Manager synced via External Secrets, cloud access via IRSA — no static keys. A versioned shared library gives every repo a five-line Jenkinsfile with built-in gates: unit tests, SonarQube quality gate, Trivy and dependency scanning, gitleaks, SBOM and cosign signing. CD is GitOps: Jenkins bumps the image tag in an env repo, Argo CD syncs with canary rollouts, prod via reviewed PR. Prometheus/Grafana monitor queue, agents and heap with alerts; volume snapshots plus config-in-Git give RPO 1h / RTO under 30 minutes, and every upgrade goes through a staging controller first.
