# Security Buzzwords

[← Buzzwords index](README.md)

| Term | Meaning |
|------|---------|
| AAA | Authentication, Authorization, Accounting |
| AuthN vs AuthZ | Who are you vs what may you do |
| ABAC / RBAC / ReBAC | Access by attributes / roles / relationships |
| Attack surface | Everything an attacker can reach |
| Blast radius | How much breaks if one thing is compromised |
| Break-glass account | Emergency admin access, heavily audited |
| CIA triad | Confidentiality, Integrity, Availability |
| CSPM / CNAPP | Cloud security posture mgmt / cloud-native app protection platform |
| CSRF | Trick browser into sending authenticated request |
| CVE / CVSS / CWE | Vulnerability ID / severity score 0–10 / weakness category |
| Defense in depth | Multiple layered controls |
| DAST / SAST / SCA / IAST | Dynamic / static / dependency / instrumented testing |
| EDR / XDR | Endpoint / extended detection and response |
| Encryption at rest / in transit | Stored data encrypted / network traffic encrypted (TLS) |
| Envelope encryption | Data key encrypts data; master key (KMS) encrypts data key |
| HSM / KMS | Hardware security module / managed key service |
| IDOR | Accessing others' objects by changing an ID |
| Injection (SQLi, command) | Untrusted input executed as code |
| JIT access | Temporary privileges granted on demand |
| Least privilege | Minimum permissions needed |
| MFA / 2FA | Multiple authentication factors |
| OWASP Top 10 | Most critical web app risk list |
| Passkey / FIDO2 / WebAuthn | Phishing-resistant public-key login |
| Penetration test | Authorized simulated attack |
| PKI / CA | Public key infrastructure / certificate authority |
| PII / PHI / PCI | Personal / health / payment card data (regulated) |
| Poisoned pipeline execution | Malicious CI config change running with CI secrets |
| Privilege escalation | Gaining more rights than granted |
| RCE | Remote code execution |
| Red / blue / purple team | Attackers / defenders / both collaborating |
| Rotation | Regularly replacing secrets/keys |
| SBOM | Software bill of materials |
| Secret sprawl | Secrets copied across many places |
| Secrets manager | Vault, AWS SM: store/rotate/audit secrets |
| SIEM / SOAR | Central security log analysis / automated response |
| SLSA | Supply-chain integrity levels framework |
| SOC / SOC 2 / ISO 27001 | Security ops center / audit report / security standard |
| SSO | One login for many apps |
| SSRF | Server tricked into requesting internal URLs |
| Supply chain attack | Compromise via dependencies/build tools (SolarWinds, xz) |
| Threat modeling (STRIDE) | Spoofing, Tampering, Repudiation, Info disclosure, DoS, Elevation |
| Typosquatting | Malicious package with similar name |
| XSS | Injecting script into pages others view |
| Zero-day | Vulnerability with no available patch |
| Zero Trust | Verify every request; no implicit trust by network |
